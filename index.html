How to Use the Registry

A short guide to reading and citing records in this ledger.

  1. Find a company or a part

    Open the Companies or Parts tab and use the search box to filter by name. Every record stays visible until you search, so you can also just scroll.

  2. Read the registry ID

    Each record carries a permanent ID in the form NCR-C-#### for companies and NCR-P-##### for parts. Use this ID, not the name, when referencing a record in a report — names can repeat, IDs never do.

  3. Check the score

    A company's score is its average standing for the quarter, from 0–100, based on inspection pass rates, defect reports, and on-time delivery. The colored tag under each name shows the tier at a glance: green for strong standing, blue for steady, amber for under review.

  4. Check the part count

    The number on a part record is a running total of how many certified builds have logged that part since it was first filed — not a current stock count.

Before you cite a record Scores refresh at the end of each quarter. If you're citing a figure in a formal document, note the cycle it came from — for example, "87.4, Q3 2026" — since the same company's score will change next cycle.
